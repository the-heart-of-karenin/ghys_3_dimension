# 一个几何反模型：仿射叶状结构与稠密等度连续作用仍不够

**性质边界。** 本文件不反驳研究目标。构造中没有全纯 Anosov 映射。它反驳的是一个候选中间引理：不能仅由“全纯稳定型叶状结构、两侧完备复仿射/欧氏叶、忠实平移 monodromy、稠密等度连续 C 作用”推出整个流形为复环面。

构造只使用经典椭圆曲线、O(1) 的截面和标记复环面族，不使用近期结果。

## 1. 具有实平凡化的非平凡全纯向量丛

取椭圆曲线 E，及非恒定全纯映射 phi:E->P^1，次数记为 d>0。设

    V = phi^*(O(1) + O(1)).

对 w=(a,b) 属于 C^2（此处把 C^2 只视为实四维向量空间），定义 O(1)+O(1) 的截面

    s_w([s:t])=(a s-conjugate(b)t, b s+conjugate(a)t).

该截面对 w 实线性。恒等式

    |a s-conjugate(b)t|^2 + |b s+conjugate(a)t|^2
      = (|a|^2+|b|^2)(|s|^2+|t|^2)

说明在每个点，[w -> s_w] 的求值是 R^4 到该纤维的实线性同构。拉回到 E，得到 V 的全局实平凡化；这些平凡化截面各自全纯，但不能作为全纯复标架。

## 2. 取一个实格形成紧致复四维流形

在实六维空间 C_l + R^4_w 中选取一般的满格 Lambda；可同时要求 C_l 在该实六维环面中稠密、Lambda 与 C_l 的交为零、投影 (c,w)->c 在 Lambda 上无核。这些各只排除可数多个真线性/有理条件。它在全纯丛 C_l + V 的总空间上按

    (c,w):(e,l,v) -> (e,l+c,v+s_w(e))

作用。每个变换全纯，作用自由且正常不连续。实平凡化把商识别为

    X topologically/differentiably = E x ((C+R^4)/Lambda),

故 X 紧致、连通，底层是实八维环面。商映射 pi:X->E 是全纯满下沉。

该流形不是复环面。事实上

    T_{X/E} = pi^*(C + V),
    c_1(TX)=pi^*c_1(V).

零截面给出 pi 的全纯截面；因此在这条椭圆曲线上 c_1(TX) 的次数为 2d，非零。而复环面的第一 Chern 类为零。

## 3. 忠实仿射 developing 与全纯余维一叶状结构

商上有两个全局闭全纯一形式：从 E 拉回的 dz，以及由 C_l 坐标导出的 dl。后者在格变换下不变，因为 l 只增加与 e 无关的常数 c。

取

    theta=dl+kappa dz.

适当一般的格 Lambda 可使投影 (c,w)->c 在 Lambda 上无核。进一步避开可数多个 kappa，使周期表示

    Lambda + pi_1(E) -> C,
    ((c,w),gamma) -> c+kappa gamma

忠实。theta 无零点，F=ker(theta) 为全纯余维一叶状结构。

万有覆盖是 C_l 与 V 在 C_z 上的拉回的直和总空间。C 上的全纯向量丛平凡，故它双全纯于 C^4。Developing 函数为

    D=l+kappa z.

每个纤维 D^{-1}(b) 是 C 上的秩二全纯向量丛总空间，因而双全纯于 C^3。周期表示忠实，故这些纤维不被非平凡覆盖变换保持；原流形中的叶本身也双全纯于 C^3。

## 4. 横截的稠密等度连续 C 作用

使用实坐标 (e,[l,w])，定义

    T_t(e,[l,w])=(e+t,[l+alpha t,w]),  t 属于 C。

这是实八维环面上的平移作用，故光滑且等度连续。选择一般的 alpha，可使其每条轨道稠密且无非零周期。理由是对偶格中每个非零字符在该实二维平面上恒为零只排除可数多个 alpha；同时可令 alpha+kappa != 0。

对固定初值，轨道映射全纯：在全纯丛坐标中，沿轨道有

    e(t)=e_0+t,
    l(t)=l_0+alpha t,
    v(t)=s_w(e_0+t),

最后一个表达式是全纯截面的取值。因此每一轨道是具有完备仿射参数的 C 叶，且

    D(T_t x)=D(x)+(alpha+kappa)t.

它与 F 横截；F 在这些横截叶间的 holonomy 是仿射的。

这些作用变换并不全纯。否则其在 Homeo(X) 中的稠密平移闭包也全由全纯自同构组成（连同逆映射取一致极限），给出实八维环面的传递全纯作用。阿贝尔传递作用的基本全纯向量场会给出全纯切丛标架，违反 c_1(TX) != 0。亦可在局部 twistor 坐标中直接看见生成向量场的共轭纤维坐标系数。

## 5. 对目标证明的启示

- 不能把 05 文件得到的“等度连续且轨道稠密”直接升级为“作用变换全纯”。
- 即使把所有高维稳定型叶加强为 C^{n-1}，上述几何推理仍有反模型。
- 这里平移闭包甚至是光滑的实环面作用；关键缺少的是一个保持复结构、以双曲自同构正规化它的映射。
- 如果在该模型中有这样一个光滑双曲正规化子，它在实环面平移坐标中必须是仿射的；不变张量论证会使复结构常值，与 c_1 非零矛盾。
- 真正待证的是如何从原始 Anosov 假设取得平移闭包/拓扑共轭的必要正则性，或找出一个不依赖此正则性的替代论证。
