# 重要闭合步骤：不变光滑体积足以完成全部刚性

**条件性定理。** 在原题设下，若 f 保持一个严格正的光滑体积形式，则 X 为复环面，且 f 双全纯共轭于双曲复线性自同构。

新增体积条件尚未从原题设推出。本节的作用是把余下目标集中到“产生不变体积”，不把它作为允许增加的假设。

## 1. 体积约束给出一阶图变换收缩

取逆映射后设 rank_C E^u=1，记 k=n-1。Ghys Proposition 2.2 给出 E^s 为全纯子丛。

取连续 Hermitian 度量，使 E^s 与 E^u 正交，并把其体积归一为给定不变体积。该度量与任意光滑度量统一等价。用 f 的一个充分大迭代 F，确保在此度量中

    s_1(x) >= ... >= s_k(x) > 0,   s_1(x) <= q < 1,
    u(x) > 1,

其中 s_i 为 DF|E^s 的复奇异值，u 为 DF|E^u 的唯一复奇异值。F 保持体积且复线性，因此逐点有

    u(x) product_i s_i(x)=1.

F 在不稳定复直线附近的 Grassmann 图变换，其垂直导数在 E^u 处为

    Z -> A_s Z A_u^{-1},

范数不超过 s_1/u。基映射 F^{-1} 的微分范数为 1/s_k。因此一阶图变换的关键系数为

    gamma(x)=s_1(x)/(u(x)s_k(x))
            =(product_i s_i(x)) s_1(x)/s_k(x).

k>=2 时，这等于 s_1^2 s_2 ... s_{k-1}，不超过 q^k<1；k=1 时等于 1/u=s_1<1。

严格不等式有统一余量，故可以把用于估计的连续度量换成充分接近的光滑度量，仍保持一阶图变换收缩。

标准不变截面/图变换正则性因此给出 E^u 为 C^1（事实上 C^{1+epsilon}）。可直接看导数递推：从一个足够接近 E^u 的光滑补丛出发，图变换在 C^0 中收敛；其导数递推的线性部分范数统一小于 1，非齐次项随 C^0 截面收敛，于是导数亦一致收敛。这里需要的正是上面的 gamma<1，不能仅用 C^0 图变换收缩替代。

## 2. 反全纯导数也被同一不等式压缩

对 C^1 复直线子丛 E^u 定义张量

    B_x: T_x^{0,1}X tensor E_x^u -> E_x^s,
    B(vbar,e)=pr_{E^s}(bar-partial_{vbar} e).

投影沿 E^u 取，故这是与局部截面选择无关的张量。每片不稳定叶是复子流形，所以 B 在 bar(E^u) 上为零；它实际属于

    Hom_C(bar(E^s) tensor E^u,E^s).

F 全纯且保持两分布，故

    B_{Fx}(bar(A_s)vbar,A_u e)=A_s B_x(vbar,e).

因此

    ||B_{Fx}|| <= s_1/(u s_k) ||B_x|| <= gamma_0 ||B_x||,
    gamma_0<1.

X 紧致，B 有界；向后迭代并使用该向前收缩，得到

    ||B_x|| <= gamma_0^m sup_X ||B|| ->0.

故 B=0。一个 C^1 Grassmann 截面的 bar-partial 为零，说明它全纯，因此 E^u 为全纯子丛。

## 3. 用平移作用完成均匀化

满支撑不变体积使非游荡集为全流形；谱分解与连通性给出传递性。Ghys Theorem B 及其证明因此给出环面拓扑模型、横向仿射 developing D、忠实平移 monodromy，以及无零点的闭全纯一形式 theta。

现在 E^u 已全纯，且 theta|E^u 处处非零。于是由

    V belongs to E^u,   theta(V)=1

定义的全局向量场 V 全纯。它在紧致 X 上生成全纯 C 作用，其参数就是不稳定叶的仿射 developing 平移。

05 文件已经证明这一 C 作用与线性实环面上的不稳定平移作用拓扑共轭。因此它等度连续，轨道稠密，其在 Homeo(X) 中的闭包为紧致阿贝尔传递群 G，同胚于实 2n 维环面。

G 中每个变换以及其逆都是全纯变换的一致极限，因此为全纯自同构。Aut(X) 是复 Lie 群，G 是其紧致 Lie 子群。G 的基本全纯向量场彼此交换并处处张成复切空间；从中取 n 个在一点复线性无关的向量场，G 的传递性及交换性使它们处处无关。

这些完备交换全纯向量场给出 C^n 在 X 上的传递全纯作用。稳定子离散，紧致性使其为满格 Lambda，故 X 双全纯于 C^n/Lambda。

最后使用 02 文件引理 B：f 在复环面上仿射，其线性部分双曲，换原点消去平移项，得到原目标中的 h f=A h。

## 4. 结合典范丛路线

08 文件第 1–3 步从 K_X 的 Bott–Chern 伪有效性构造与 Lebesgue 等价的不变概率测度，并取得传递性。再使用其第 4 步明确列出的经典绝对连续密度正则性定理，便得到本定理要求的光滑体积。

因此：

    原题设 + K_X 伪有效  =>  原目标的全部结论。

剩余关键不是再补一个全局仿射联络，而是从原始假设证明存在这样的测度/体积，或证明 K_X 伪有效，或找到另一条能替代体积等式的收缩估计。
