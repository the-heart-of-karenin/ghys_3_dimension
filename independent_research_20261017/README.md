## 目标

设 X 是复维数 n >= 2 的紧致连通复流形，f 是全纯 Anosov 微分同胚，稳定或不稳定复子丛之一的秩为 1。目标是证明 X 双全纯同构于复环面，且 f 双全纯共轭于保持格的双曲复线性自同构。

不额外假定 Kähler、射影、保体积、传递性或不变分布的全纯性。若这些性质用于论证，须从假设证明。

## 工作原则

不得把叶的复结构视为分布的全纯性；不得把拓扑共轭视为双全纯共轭；不得把有限覆盖为环面视为原流形为环面。证明完成须逐一核验所用定理的全部假设。
